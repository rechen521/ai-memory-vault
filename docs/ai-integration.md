# 和 AI 配合使用

这个工具本身不调用任何模型 API，它解决的是**人的问题**：把散落在几十个会话里的关键信息，压成一段随时能粘贴的上下文。

## 典型工作流

```
对话里出现值得长期记住的信息
        ↓  粘贴到「批量导入整段对话」或手工录入
   记忆库里留下条目（带标签、重要度）
        ↓  切换到新会话 / 换模型 / 上下文被截断
  「生成上下文快照」→ 复制
        ↓
粘贴到新会话的第一条消息，然后正常提问
```

## 三种粘贴方式

**1. 直接粘贴（最省事）**

把快照原样粘在第一条消息最前面，后面接你的问题：

```
<粘贴快照>

---
接着上面的背景，帮我比较一下 A 大和 B 大的计算机专业。
```

**2. 当作系统提示词（更稳）**

支持自定义 system prompt 的客户端（Claude Projects / ChatGPT 自定义指令 / 各类 API 调用），把快照完整放进 system 角色里，比放在用户消息里更不容易被截断。

**3. 存成文件让 AI 自己读**

把导出的 `ai-memory-vault-*.json` 或快照 `.md` 放进项目目录，在支持文件读取的 AI 里直接让它读：

> 我的长期记忆在 `memory.md` 里，先读它，再回答我的问题。

## 写给 AI 的一句话

如果客户端支持固定指令，这一句很管用：

> 下文我会提供一份「上下文快照」，请把它当作已确认的已知事实；不要重复询问其中已有的信息，也不要与之矛盾。若我后续的表述与快照冲突，以我最新说的为准，并主动指出冲突点。

## 关于筛选范围

快照在筛选状态下会写明 `已筛选：标签 #x + 关键词 y`。如果希望 AI 掌握全部背景，生成前请先清空搜索框和标签筛选，让列表显示全部记忆。

## 数据流向

- 记忆只存在浏览器 `localStorage` 和你自己绑定的本地 JSON 文件里；
- 应用不发任何网络请求（唯一的外链是页脚的 GitHub 仓库地址）；
- 粘进对话的快照会交给你所选 AI 服务的隐私策略管，**敏感信息建议先用标签筛掉再生成快照**。
